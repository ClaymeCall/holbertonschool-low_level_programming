# Holberton School - Low-Level Programming

This repository and project were made in the context of learning at Holberton School. The project goal was to learn about low-level programming using the C language, including memory management, pointers, data structures, and systems programming.

## Repository Structure

- **argc_argv**: Command-line argument handling
- **bit_manipulation**: Bitwise operations and bit manipulation
- **doubly_linked_lists**: Doubly linked list implementation
- **file_io**: File input/output operations
- **function_pointers**: Function pointers and callbacks
- **functions_nested_loops**: Functions, nested loops, and recursion
- **hash_tables**: Hash table data structure implementation
- **hello_world**: Introduction to C programming
- **malloc_free**: Dynamic memory allocation and management
- **more_functions_nested_loops**: Advanced function and loop concepts
- **more_malloc_free**: Advanced dynamic memory techniques
- **pointers_arrays_strings**: Pointers, arrays, and string manipulation
- **recursion**: Recursive functions and algorithms
- **singly_linked_lists**: Singly linked list implementation
- **structures_typedef**: Structures and type definitions
- **variables_if_else_while**: Variables, conditionals, and loops
- **variadic_functions**: Variadic functions and variable arguments
